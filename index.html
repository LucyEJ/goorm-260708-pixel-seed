문제

명언 앱, 왜 금방 잊혀질까요?

매일 아침 수많은 정보와 알림으로 하루를 시작하지만, 하루를 바꾸는 것은 거창한 목표보다 단 하나의 좋은 생각일지도 모릅니다.

  • 텍스트 중심이라 쉽게 소비되고 잊힌다
  • 시각적 즐거움이 부족하다
  • 반복 사용의 동기가 약하다
  • 대부분 비슷한 디자인과 콘텐츠를 제공한다
해결

같은 문장, 매일 다른 감성

"오늘은 어떤 그림이 나왔을까?"를 기대하며 자연스럽게 앱을 다시 방문하게 됩니다.

핵심 기능

하루 10초, 작은 루틴

매일 하나의 메시지와 하나의 픽셀 아트. 몇 초 만에 오늘의 작은 영감을 얻을 수 있습니다.

Gemini API를 활용해 매일의 문장을 기반으로 픽셀 캐릭터, 소품, 풍경을 자동 생성합니다. 동일한 문장이라도 매번 새로운 결과가 만들어집니다.

Pixel Seed는 생산성을 높이는 앱이 아닙니다. 하루를 조금 더 가볍게 시작하도록 돕는 감정 경험을 제공합니다.

  1. 01

    앱 실행

    아침, 잠깐의 시간을 내어 Pixel Seed를 엽니다.

  2. 02

    오늘의 픽셀 아트

    AI가 새로 그린 16bit 스타일 이미지가 등장합니다.

  3. 03

    5초 동안 읽기

    오늘의 한 문장을 천천히, 부담 없이 읽습니다.

  4. 04

    나만의 Pixel Companion이 조금씩 자랍니다.

  5. 05

    하루 시작

    작은 영감과 함께 오늘을 시작합니다.
